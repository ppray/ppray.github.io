四题主线一句话串起：Q1 十二词按「回答什么问题」分四类（一价定律 → 购买力平价 → 利率平价的汇率三件套 → 铸币税 → 微笑曲线与雁行模式两模型 → 康波长波），四个提出者必写；Q2 五词按「病在哪一层」分三类（宏观失衡：资产泡沫、滞胀 → 结构困境：资源诅咒、去工业化 → 制度缺陷：预算软约束），逐层深入；Q3 三阶段按「地域扩散＋驱动力更替」（政策压 → 改革压 → 结构压），第三阶段的「宽货币、低通胀」背离三条机制＝货币乘数崩塌＋贫富分化压需求＋产能过剩压价格；Q4 四派按「债务乐观度」排光谱（鸦片 → 中性 → 阈值 → MMT）＋ 翟氏撕开点「内债是分配、外债是主权」。最高频失分点：一价定律与购买力平价放反、把四派分类坐实为翟东升原创。
