📊 什么是净信用余额？

净信用余额 = (现金账户自由信用余额 + 保证金账户信用余额) − 融资债务

  • 正值：投资者整体持有更多现金储备，市场杠杆较低，通常出现在市场底部或熊市恐慌期。
  • 负值：投资者整体使用杠杆（借钱炒股）超过现金持有量，市场风险偏好高，牛市后期常见。
  • 负值越深：市场杠杆越高，泡沫化风险越大。历史上，净信用余额创纪录低位往往与市场顶部高度相关。

🔍 如何解读与使用？

  • 趋势观察：关注净信用余额的方向和斜率，而非绝对值。快速转负或加速下行是危险信号。
  • 历史类比：对比 2000 年互联网泡沫、2007 年金融危机和 2021 年杠杆高峰期的净信用余额水平。
  • 逆向指标：当净信用余额快速由负转正（投资者集体去杠杆），往往意味着市场已处于极度恐慌、可能接近底部。

🤖 自动化更新机制 (GitHub Actions)

  • 月度定时更新：工作流 .github/workflows/update-finra-margin.yml 每月 26 日自动抓取 FINRA 官网最新数据并提交到仓库。
  • 手动立即触发：进入 GitHub 仓库 ➔ Actions ➔ 选中 update-finra-margin ➔ 点击 Run workflow 即可一键更新。
  • 本地更新命令：也可以在本地运行 python3 finra-margin/update_data.py 自动解析更新。
