## 1. 切分与依赖（修正后）

原方案主张"必须先 L2 后 L3"。核对代码后：**只有 L3c(FDI→gradient 桥) 依赖 L2**；L3a(国际收支闭合)独立于 L2，可并行。

```
P0（同补丁，必须一起过门禁）
  ├─ L2a  产业梯度成本乘数（只碰预算路径，不碰利润率）   ← 独立
  └─ L3a  国际收支闭合（通电 tradeBalance → NFA）        ← 独立

P1（各自单独过门禁，不与 P0 同补丁）
  ├─ L2b  梯度衰减（关税/FDI 条件）        ← 依赖 L2a
  ├─ L3b  银本位 fxIndex + priceLevel       ← 依赖 L3a
  └─ L3c  FDI 政策卡 + 利润汇回             ← 依赖 L2a（桥接 gradient）

P2  事件卡 + UI 可视化
```

**贯穿原则（沿用 v3.3 教训）**：不在同一补丁同时改成本侧和价格侧；所有数值经 `tools/balance.js` 反解标定后才定稿。

## 2. L2a —— 产业梯度成本乘数（P0）

### 2.1 新增数据文件

```js
// js/data/gradient.js  (新增)
import { BUILDINGS } from './buildings.js';

// 建筑→梯度映射（真实 building id）。T0 = 初级/原材料，无梯度约束。
export const INDUSTRY_TIERS = {
    T0: ['rye_farm', 'cotton_plantation', 'iron_mine', 'coal_mine'],
    T1: ['textile_mill'],          // 轻工业
    T2: ['steel_mill'],            // 重工业
    T3: ['tool_works', 'arms_factory'], // 高端/资本品
};

// 成本乘数：该国建该梯度建筑，预算口径 buildCost 乘此数。T0 恒 1.0。
// ⚠ 起始占位值，必须经 tools/balance.js 分国可行性断言标定后定稿（§2.5）。
export const INDUSTRIAL_GRADIENT = {
    GBR:  { T1: 1.0,  T2: 1.0,  T3: 1.0  },  // 核心：基准
    PRS:  { T1: 1.1,  T2: 1.15, T3: 1.3  },  // 半核心：追赶中
    USA:  { T1: 1.05, T2: 1.2,  T3: 1.5  },  // 半边缘：资源丰裕但资本品依赖进口
    QING: { T1: 1.3,  T2: 1.7,  T3: 2.5  },  // 边缘：技术断层最大
};

// 解锁门槛：新建本级需先有 N 座低一级。硬约束，仅作用于"新建"，不追溯既有建筑。
export const TIER_UNLOCK = {
    T2: { requiresTier: 'T1', minCount: 2 },
    T3: { requiresTier: 'T2', minCount: 2 },
};

export function tierOf(buildingId) {
    for (const [tier, ids] of Object.entries(INDUSTRY_TIERS)) {
        if (ids.includes(buildingId)) return tier;
    }
    return 'T0';
}

// ★ 核心纯函数：有效建造成本。只进预算/可负担性路径（§2.2 的 7 个注入点）。
//   绝不替代 pops.js:114 / ai.js:21,40 里的 buildCost——那三处是运行期利润率/决策口径，
//   动它们就破坏 P0"不碰利润率"承诺（详见 §2.4 红线）。
export function effectiveBuildCost(countryCode, buildingId) {
    const base = (BUILDINGS[buildingId] && BUILDINGS[buildingId].buildCost) || 0;
    const tier = tierOf(buildingId);
    if (tier === 'T0') return base;                         // 初级恒为基准
    const g = INDUSTRIAL_GRADIENT[countryCode];
    const mult = g ? (g[tier] || 1) : 1;
    return Math.round(base * mult);
}

// 解锁判定。既有建筑视为已满足（不追溯）。
export function isTierUnlocked(nation, buildingId) {
    const tier = tierOf(buildingId);
    const req = TIER_UNLOCK[tier];
    if (!req) return true;
    const have = (nation.buildings && nation.buildings[req.requiresTier]) || 0;
    return have >= req.minCount;
}
```

**解锁门槛与初始建筑的相容性核对**（用 `countries.js:14-23/51-60/87-96/124-133` 实数）：

| 国 | T1(textile) | 可建 T2? | T2(steel) | 可建 T3? |
|---|---|---|---|---|
| GBR | 20 | ✓ | 10 | ✓ |
| PRS | 8 | ✓ | 6 | ✓ |
| USA | 10 | ✓ | 5 | ✓ |
| QING | 3 | ✓ | **0** | ✗ 需先建 2 座 steel_mill |

→ QING 起手无法新建 tool_works/arms_factory（既有 arms=1 不追溯，仍可运行）。这正是边缘国"先轻后重再高端"的阶梯，ISI 路径有了真实节奏。门槛**不追溯**，无回溯非法问题。

### 2.3 红线：这三处 `buildCost` 绝不能动

| 文件:行 | 用途 | 为什么不动 |
|---|---|---|
| `pops.js:114` | 运行期折旧 `(buildCost||0)*0.02*count`，进工资前置残差 | 动它 = 改运行期利润率 = 重跑 wage-first 残差核算，违背 P0 承诺 |
| `ai.js:21` | `computeUnitCost` 的 upkeep | AI 蛛网"扩产/降开工"阈值（`ai.js:128,141`）的决策口径 |
| `ai.js:40` | `computeProfitRate` 的 upkeep | AI 新建候选排序（`ai.js:170-174`）的决策口径 |

`effectiveBuildCost` 只改变"花多少钱能建"，不改变"建成后赚不赚"。这是 P0"不碰利润率"边界的**精确定义**：gradient 渗进预算路径（§2.2），止步于决策/利润路径（本节）。若未来 P1 想让 gradient 也反映"技术落后导致运行低效"，那是新决策，须单独过门禁。

### 3.3 守恒断言的订正（重要）

原方案 §2.3 主张 `ΣΔReserves = 0`。**这不成立**：逐国 tradeBalance 之和 = `Σ_g worldP_g × (globalS_g − globalD_g)`，而全局 S/D ∈ [0.7, 1.4] 是**设计目标**（`balance.js:117`），并非 S=D，故价值和不为 0。这恰恰是 `invariants.test.js:13-16` 当年废除"净出口和==0"的同一条理由。

因此 L3a 的断言是**有界性**，不是零和：

| 新断言 | 内容 | 落点 |
|---|---|---|
| tradeBalance 簿记一致 | `Σ_n tradeBalance_n ≈ Σ_g worldP_g × (globalS_g − globalD_g)`，容差 1（取整误差量级） | `invariants.test.js` 新 Test 5 |
| NFA 不发散 | 50 回合内 `|netForeignAssets|` 不超过初始绝对值的 10 倍（与蛛网 10× 约定一致）；若违反说明参数不稳 | 插入 `invariants.test.js:134-149` 蛛网循环 |

});

> 注意：**P0 落地后这两个新断言很可能一开始就失败**（NFA 因无价格反馈单向漂移；ISI 因梯度过陡）。失败是标定信号，不是回滚信号——按 `detail` 调 gradient 表 / 投资池系数，重跑 `npm test` 直到全绿。这与项目"数字由脚本产出不由手算"的第一原则一致。

## 5. P1 概要（独立补丁，各自过门禁，此处仅锁定接口）

### L2b 梯度衰减
- 衰减条件：`tariff[g]>阈值` 或 `FDIStock(→该国,sector)>0`，否则不衰减。
- 公式：`gradient(t+1) = 1 + (gradient(t)−1)×decayRate`，clamp 下限 1。
- 落点：`gradient.js` 新增 `computeGradient(code, tier, nation, turn)`，`effectiveBuildCost` 改读它（仍是纯函数，仍只进预算路径）。
- 风险：会改变有效成本走势 → 单独跑 `npm test` 蛛网 + ISI 可达性。

### L3b 银本位 fxIndex + priceLevel
- `goldSilverRatio(turn)`：`turn<34 ? 15.5 : 15.5+(turn−34)*0.45`（t=64≈29，量级对齐史实）。
- `fxIndex`：金本位国=1；银本位国(QING)=`goldSilverRatio(t)/goldSilverRatio(0)`。
- **单一 hook**：只在 `market.js` 计算 `tradeBalance` 时，把银本位国的进出口值 `× fxIndex` 换算到黄金计价。**不进 `domesticPrices`、不进关税楔子、不进运费楔子**（`core.js:236-247`），避免与现有三层价格机制叠加双重计数。
- `priceLevel(t+1) = priceLevel(t) × (1 + λ × ΔReserves/reserves)`，λ 与现有 0.20 阻尼同量级标定。接入前单独验证不产生"FDI流入→梯度降→出口增→储备增→价格升→竞争力降→FDI流出"极限环。

### L3c FDI + 利润汇回
- GBR 可将资本投入外围国产业，冲抵 L2a gradient：`effectiveGradient = base × (1 − FDIScount × min(1, FDIStock/threshold))`，clamp 下限 1（FDI 不能把梯度打到 1 以下）。
- 代价：`profitRepatriation = FDIStock × repatriationRate`，每回合计入两国（东道国 NFA 减、来源国 NFA 加）——直接接 §3.1 的 tradeBalance/NFA 通道。
- 政策卡：QING/PRS 可选"限制利润汇回"（降 repatriationRate，但吓退新增 FDI）。
- 这是唯一**真正依赖 L2a** 的 P1 项。

## 7. 风险与回滚

1. **ISI 可达性失败**：若 Test 6 持续不绿，优先调降 QING 的 T2/T3 梯度（1.7/2.5 → 1.5/2.0），而非动胜负阈值 `rules.js:19`。胜负条件是教学锚点，不应为可玩性让步；梯度是可标定参数。
2. **NFA 单向漂移**：P0 不闭合价格反馈，顺差国 NFA 可能单调增长。10× 断言会先报警。若需在 P0 内收敛，临时给 NFA 加 `×0.98/回合` 的均值回归（模拟储备不会无限堆积），P1 用 priceLevel 正式替换。
3. **steel 与 T2 的错位**：steel_mill 是 T2，但 steel 不计入 ISI 分子（`market.js:97-103`）。L2a 会让 QING 建钢厂更难，而建钢厂本身又不直接帮 QING 胜利——钢厂的价值是解锁 T3（tool_works/arms，这些才算 ISI 分子）。这条耦合是**正确的**（钢→机械→出口制造品，正是 ISI 链条），但需在图鉴/手册里向玩家讲清"建钢厂是为了解锁下游，不是直接冲出口指标"。
4. **回滚**：P0 全部改动集中在 `gradient.js`（新文件）+ 6 处 ai.js + 3 处 ui.js + market.js tradeBalance + 门禁。回滚 = 删 `gradient.js`、revert 其余、`tradeBalance` 重新归零（NFA 回到冻在初值的老行为）。无数据迁移、无状态破坏。
