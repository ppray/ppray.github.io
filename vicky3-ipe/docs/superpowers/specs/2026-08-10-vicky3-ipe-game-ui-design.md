# 《帝国的账本》游戏 UI 改造设计 v1.0

## 背景

当前 `index.html` 是一个仪表盘式网页：顶部统计条 + 标签页 + 侧边日志，功能完整但缺少"游戏画面"感。本设计把 `index.html` 改造成以复古海图为主视觉、右侧常驻操作面板为辅的大战略游戏界面，同时保留 `dev.html` 作为引擎调试入口。

## 目标

- 让玩家打开 `index.html` 的第一眼感觉是"游戏"而不是数据面板。
- 保留并充分利用现有引擎接口：`js/ui.js` 的单状态 + 全量重绘架构、`js/engine/*`、`js/data/*`。
- 在可接受的实现量内完成 M0，留下清晰的后续迭代边界。

## 非目标

- 不做精确地理信息系统、不做省份地块、不做战争/军事地图层。
- 不做音效、音乐、多语言、动画骨骼。
- 不改动引擎经济模型（M1–M3 已验证的数据和规则保持不变）。

## 总体布局

```
┌─────────────────────────────────────────────────────────────┐
│  🇬🇧 大英帝国  1836年 第1回合  🪙5000  📊1200  👑90%  ⌛下一回合  │
├──────────────────────────────┬──────────────────────────────┤
│                              │  🏛️ 政治关税 │ 🏭 产业 │ 🌐 市场 │ 📜 图鉴 │
│                              │                              │
│      复古海图 (SVG)          │  右侧面板内容区               │
│                              │                              │
│      - 四国陆块              │  - 当前 Tab 的操作与数据       │
│      - 建筑图标              │  - 事件日志（底部可折叠）       │
│      - 贸易航线              │                              │
│                              │                              │
└──────────────────────────────┴──────────────────────────────┘
```

- 地图占左侧约 55–60%，右侧面板约 40–45%。
- 顶部资源条固定高度，包含当前国家、年份/回合、国库、GDP、霸权度、ToT、下一回合按钮。
- 右侧面板顶部是 Tab 导航，底部常驻事件日志（可折叠）。

## 地图层（SVG）

### 视觉风格

- 羊皮纸底色海洋 `#c9b184`，带淡色横向纹理线模拟海图纬度线。
- 陆块使用三种土绿色/赭黄色/棕黄色色块，区分欧洲、亚洲、美洲。
- 国境线用深褐色 `#3a2f1a` 描边，宽度 1.5–2.5。
- 罗盘装饰位于右上角，标题水印位于底部中央 `～ MARE LIBERUM · 1836 ～`。
- 四国填充色：
  - GBR：蓝灰 `#7a8aa0`
  - PRS：铁灰 `#8a8a92`
  - QING：赭红 `#b06a4a`
  - USA：绿 `#6a8a72`

### 地图内容

- **大陆轮廓**：手绘简化 SVG path，不要求精确地理，但四大陆位置可辨认。
- **建筑图标**：按各国拥有的建筑类型显示在对应国土内。数量大时聚合为带数字的气泡。
- **贸易航线**：用虚线贝塞尔曲线连接相关国家，方向用箭头/流量标注表示。M0 为静态虚线，后续可加 CSS 流动动画。

### 交互

- 点击国家陆块 → 切换主视角到该国（更新顶部资源条，右侧面板同步刷新）。
- 点击建筑图标 → 右侧面板自动切换到"产业"Tab，并滚动高亮对应建筑卡片。
- 鼠标悬停国家/建筑 → 显示工具提示（国家名 + 关键指标，或建筑名 + 数量）。

## 右侧面板

### Tab 导航

保留四个 Tab：

1. **🏛️ 政治关税**
   - 国家选择器（和顶部条同步）。
   - 阶级 Clout 与要素收益条形图（地主、资本家、工人）。
   - 关税滑杆（8 种商品）。
   - 所得税率滑杆。
   - 亏损产业补贴开关。
   - 底部：生存部门人数、就业紧缺度 `u`、当前工资率、投资池、海运安全度、净外债。

2. **🏭 产业**
   - 建筑卡片网格，每张卡显示：名称、数量、建造成本、人头规模、产出/投入、要素比、盈利状态。
   - 点击卡片"建造"按钮触发建造（扣款 + 重绘）。
   - 被地图建筑点击联动时，滚动到对应卡片并高亮 1.5 秒。

3. **🌐 市场**
   - 全球市场表格：商品、分类、基准价、世界价格、本国到岸价、全球供给、全球需求、本国净出口。
   - 用颜色标识净出口（绿）、净进口（红）、平衡（灰）。

4. **📜 图鉴**
   - 现有 IPE 理论图鉴内容，保持卡片网格布局。

### 事件日志

- 放在右侧面板底部，作为可折叠条带。
- 默认高度约 120px，展开后显示最近 20 条事件。
- 日志项保持现有 `log-item` 样式，但字体和边框贴合羊皮纸风格。

## 顶部资源条

从左到右：

1. 国旗 + 国家全名（点击可展开国家选择器）
2. 年份 / 回合
3. 国库 🪙
4. GDP 📊
5. 霸权度 👑
6. 贸易条件 ToT ⚖️

## 数据流

1. `ui.js` 通过 `createInitialState(nation)` 创建状态。
2. 用户操作（调关税、建建筑、点地图国家）更新 `gameState` 局部或调用 `tick(gameState)`。
3. `render(state)` 调用：
   - `renderHeader(state)`
   - `renderMap(state)`
   - `renderSidePanel(state, activeTab)`
   - `renderLogs(state.logs)`
4. `localStorage` 自动保存当前状态（key 沿用 `empire_ledger_state_v33`）。

## 错误处理

- 地图 SVG 渲染失败时，右侧面板仍可独立工作（降级为当前仪表盘布局）。
- `gameState` 缺失或损坏时，回退到 `createInitialState('GBR')`。
- 建筑图标数量异常时，显示聚合气泡而非无限堆叠。

## 测试策略

- 保持 `npm test` 6/6 全绿（不改动引擎测试）。
- `dev.html` 继续作为调试入口，包含：
  - 运行 `balance.js` 按钮
  - 运行全套测试按钮
  - 原始数据面板（可选保留或简化）
- 手动验收清单：
  - 四国切换后地图高亮正确。
  - 点击地图建筑后产业 Tab 自动切换并高亮卡片。
  - 关税滑杆调整后顶部 ToT/GDP 变化可见。
  - 下一回合后地图航线/图标更新。
  - 移动端宽度小于 1024px 时，右侧面板可折叠或堆叠（可选 M0 支持）。

## 设计决策记录

1. **为什么选地图中心式 + 复古海图**：最接近维多利亚 3 的游戏画面感，同时和"帝国的账本"书卷气、IPE 图鉴风格统一。
2. **为什么右侧常驻面板而非全屏覆盖**：核心玩法循环是"调关税 → 看价格/阶级变化"，同屏反馈比全屏沉浸更重要。
3. **为什么把测试入口移出 `index.html`**：测试套件是开发工具，不是玩家游戏体验。
4. **为什么不做精确地图**：项目只有 4 个国家，精确 GIS 性价比低；简化海图足以承载游戏叙事。
